# v3 图层分析与逐层生图方案

> 状态：历史分析（v3 基准，2026-10-27）。其中的眼睛、脸、耳、鼻嘴已在 v4/v5 处理；头发结构仍是 v6 的计划范围。当前结论以 [docs/PROGRESS.md](../PROGRESS.md) 为准；本文保留当时的逐层证据和验收方法，不声称这些建议已全部实施。

日期：2026-10-27（香港时间）。分析对象：`live2d_v3/manifest.json` 当前 33 个显示图层，以及双眼完整虹膜与 4 个遮罩文件。本轮只读取既有资产、检查脚本并生成诊断资料，未调用生图、未修改角色 PNG / PSD / 预览。

**结论：采用“生图提供完整独立分件，抠图只做隔离和修边”的方向合理。现有分层名称与坐标可沿用，现有图层内容多数需要重做或补全。问题包括语义混层、隐藏区缺失、硬切口和低分辨率，不能靠消除锯齿一项解决。**

## 三、后续逐一执行顺序

这是执行建议，不是本轮已发出的生成任务。仍使用 Codex 官方内置生图；实际型号取决于工具提供的能力，不能声称已指定 gpt-image-2.5-sunburst。

1. **双眼形状与眉毛。** 先用原母版完整眼部作共同风格参考。逐一生成左上睑 → 右上睑 → 左下睑 → 右下睑 → 左眼白 → 右眼白 → 左完整虹膜 → 右完整虹膜 → 左眉 → 右眉。右侧同时参考原母版和左侧已接受分件，保证笔触/颜色一致。每层单独检查，不直接整批替换。裁切片与遮罩是派生文件，不消耗独立生图步骤。
2. **完整脸底、左右耳与鼻嘴。** 清除目前靠前发遮住的残片；脸底通过后再叠入第一组眼睛。头颈连接与 neck_bridge 槽位一起规划，避免生成两份下颌线。
3. **完整后发 → 固定前发 → 中心刘海。** 用同一组批准造型参考。每片都要含隐藏根部，先单层验收，再检查前后遮挡与小幅运动。当前发饰/挑染仍按固定前发内嵌处理，不额外扩大拆层范围。
4. **躯干骨盆与颈部。** 保留当前白色人台设计，先锁定身体比例、肩髋位置、线宽与灰影，再确定四肢接头。没有加入衣服重设计。
5. **左上臂 → 右上臂 → 左前臂 → 右前臂 → 左手 → 右手。** 逐层补全肩/肘/腕隐藏部分，检查手指、手外侧轮廓和错层黑线。
6. **左大腿 → 右大腿 → 左小腿 → 右小腿 → 左足 → 右足。** 保留站姿、腿长和站距，检查髋/膝/踝遮挡区；足部无需凭空增加鞋。

先完整通过一个“眼部组合”再扩大到整个人物，可以尽早验证生成分件的线条与配准是否符合目标，避免重复生成全部身体后才发现整体风格不一致。

## 四、生图与缩放约定

- **造型参考和坐标参考分开。** 原始批准正面母版提供人物造型与表情；v3 提供现有图层命名、放置坐标和问题参考。不能把 v3 的半成品眉/眼条作为正确形状照抄。
- **生成完整对象。** 单层只出现该部件，背景真实透明。被上层遮住的根部/边缘也要画完整；不要要求模型复制现在的残片轮廓。
- **先大图，后一次缩小。** 细五官建议保留至少约4倍目标尺寸的有效细节作为候选母资产；画布尺寸不能替代有效内容尺寸。若整张图很大、眼睛仍只有几十像素，没有达到目的。
- **优先等比缩放＋平移。** 使用眉心、眼角、下巴、发根、肩髋等锚点校准；若需要明显横向拉伸或局部扭曲才能对上，应退回生成调整，不能靠强行变形掩盖造型偏差。
- **大尺寸母资产保留。** 固定1024×1536的现有坐标作为首个装配目标；保存生成原图、变换比例和偏移。未来若要近景精度，可重新从大图导出更高分辨率整体；不要反复放大已缩小PNG。
- **抠图只清理背景和少量非目标像素。** 混入大片头发的眉、只有残片的下睑应重做，不再依赖阈值擦除。只有必要时才对生成输出再做轻量隔离。
- **保留透明边缘，不全图硬阈值化。** 不透明内部、软边缘和残色分别处理；不以一遍模糊掩盖锯齿，也不把自然尖发梢全部腐蚀掉。

大图生成、超采样和缩小是质量手段，**不能保证自动无齿边**；每层都需在实际显示尺寸和放大检查中验收。

## 五、每层的美术验收与整体验证

每个候选按相同顺序检查，记录“通过 / 返修 / 待确认”，不要仅记录生成成功。

1. 单层在白、深灰、棋盘三背景检查：无其它部件、背景色圈、脏点、硬矩形补丁；有意断笔应与参考一致。
2. 100%实际尺寸检查边缘与笔触，再用200%–400%检查像素；最近邻放大可定位像素，不单独用来评价最终显示质量。
3. 内容完整：耳根、发根、关节端、完整虹膜等隐藏区存在，显示片与母资产明确区分。
4. 同组一致：左右颜色、线宽、高光方向、比例与表情匹配；允许原设计的不对称。
5. 配准重组：开关上层后，下层不是空洞和残片；不靠后发掩盖坏眉毛，不靠脸色掩盖鼻嘴方块。
6. 小幅移动/旋转与视线极限测试，检查露底、固定残影、跨层漏色；功能验证和美术通过分别记录。
7. 最后才打包 PSD，检查图层名称、顺序、透明度、运行时与PSD中性一致。包装零像素差异只证明传输未改变输入，不证明输入美术正确。
