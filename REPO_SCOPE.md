# Public Repository Scope

This is a code and documentation snapshot of the current See-through character workflow. It is not the full local asset workspace.

## Included

- Current project entry and handoff documents.
- Existing Modal runner source, input preparation, and a safe configuration template.
- Anime2.5DRig test harness, validation scripts, runtime metadata, and sanitized technical summaries.
- Historical v1–v5.1 code and reports for traceability; these are not current assets.

## Excluded

- PSD, PNG, JPEG, WebP, GIF, HTML preview, MOC3, and CMO3 files.
- See-through/Anime2.5DRig upstream checkouts and pretrained model weights.
- The local `modal_run_spec.json`, Modal call IDs, billing/credit notes, credentials, and private images.
- Local workspace captures and PhotoCraft working copies.

The real PSDs and visual evidence remain in the private working tree. Report summaries include hashes and validation facts without publishing the image data.
